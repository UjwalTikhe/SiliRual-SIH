# App Icons Directory

This directory should contain the app icons in various sizes for PWA and mobile deployment.

## Required Icon Sizes:

- icon-72x72.png - iPad mini, iPad 2-3
- icon-96x96.png - iPad Pro, iPad Air
- icon-128x128.png - Android (medium)
- icon-144x144.png - iPad (retina)
- icon-152x152.png - iPad Pro (retina)
- icon-167x167.png - iPad Pro (12.9")
- icon-180x180.png - iPhone (retina)
- icon-192x192.png - Android (high)
- icon-512x512.png - Android (extra high/adaptive)

## Instructions:

1. Create icons from your SiliRual logo at the specified sizes
2. For small sizes (72-180px), simplify the design to focus on:
   - The "S" shape with elderly woman profile
   - Remove text, landscape, and fine details
   - Keep bold, recognizable shapes
3. For larger sizes (192-512px), you can include more details
4. Save all icons as PNG format with transparency (or solid background)
5. Replace the placeholder icons with your actual icons

## Tools to Generate Icons:

- https://www.favicon-generator.org/
- https://realfavicongenerator.net/
- Canva, Figma, or Adobe Express
